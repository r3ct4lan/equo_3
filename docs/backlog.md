# Бэклог Equo

Актуально на 2026-10-24. Обязательный MVP завершён и принят для тестового
использования. [Текущий контекст](product-context.md) и
[решение владельца](acceptance/owner-mvp-walkthrough.md) фиксируют результат.

В начале списка — задачи по результатам ручного тестирования владельцем.
Далее сохранены все незавершённые задачи прежнего плана с исходными ID:
24 подзадачи Should have, 9 Later и одна неблокирующая задача по зависимостям.
Функции запускаются отдельным поручением владельца. Перед реализацией сверяются
границы, бизнес-правила, API, модель данных и ADR; отдельный план требуется
только для выбранной работы. Категории определены в [MVP scope](mvp-scope.md).

- [ ] `MT-005` — **Исправить обратный отсчёт при ограничении попыток входа.**
  Таймер в сообщении «Too many sign-in attempts» визуально идёт значительно
  медленнее реального времени. Проверить отсчёт и согласовать отображаемое
  время ожидания с фактическим сроком ограничения на сервере.
  Технически исправлено 2026-10-22: срок задаётся серверным `Retry-After`,
  оставшееся время пересчитывается от него даже после паузы вкладки; повторной
  попытки входа без действия пользователя нет. `make check-full` прошёл:
  690 backend tests / 8 448 assertions и 30 browser E2E. Развёрнуто на AWS
  2026-10-22; ожидается функциональное тестирование владельцем.
  Уточнение владельца от 2026-10-22: убрать ограничение email + IP; считать
  только неверные учётные данные по IP. После пяти ошибок блокировать вход на
  60 секунд без продления повторными запросами; 1–4 ошибки обнулять через
  60 секунд без новых ошибок. Технически выполнено 2026-10-23:
  `make check-full` прошёл (693 backend tests / 8 456 assertions,
  30 browser E2E), CI PR #27 прошёл. Эта доработка ещё не развёрнута на AWS;
  ожидается функциональная проверка владельцем.

`DEBT_SHARE` удалёнными. Состав фиксируется, `MANUAL` не меняются, баланс
пересчитывается только по оставшимся активным transfers. Долг исчезает из
списка, но остаётся доступным прежним участникам по прямой ссылке как read-only
история; restore/archive не добавлены. UI требует отдельного необратимого
подтверждения и при неопределённом результате или конфликте версии блокирует
повтор до reload. Прошли backend quality и 63 профильных теста / 593 assertions,
16 frontend component tests, frontend lint/typecheck/build и изолированный
browser E2E полного сценария удаления. Итоговый полный GitHub Actions gate
остаётся общим для накопительной ветки перед слиянием в `main`.

## За пределами согласованного объёма

Импорт/экспорт, админка, мультивалютность, неравные доли, несколько плательщиков,
пользовательская дата, автоматическое погашение, расширенный поиск, скрытие связей,
архив/восстановление и финансовые уведомления не становятся задачами автоматически.
Каталог `MVP-SC-023—029` и условия изменения границ сохранены в
[mvp-scope.md](mvp-scope.md). Для включения нужны продуктовое решение и согласованные
изменения требований, API, данных и, при необходимости, ADR.
